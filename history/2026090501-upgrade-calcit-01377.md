# Upgrade Calcit 0.13.77 / 升级 Calcit 0.13.77

- Raise the template baseline from Calcit 0.13.32 to the exact 0.13.77 release.
- Move the HTTP and frozen JSON compatibility modules to their current C-safe releases, 0.3.14 and 0.0.17, so toolchain verification no longer loads legacy Rust-value dylibs.
- Consume Stir Template 0.0.12 with its merged Calcit 0.13.77 compatibility fixes, and remove the deprecated Lilac dependency now that Stir uses typed decoding directly.
- Canonicalize the Snapshot with the exact 0.13.77 CLI, bind the server entry to the existing `app.main` namespace, and pass concrete booleans to the typed JSON serializer.
- Adapt the HTML title resource to Stir Template 0.0.12's typed `Option<String>` boundary while preserving the generated `<title>` output.
- Harden CI with read-only permissions, explicit readable Action release tags, disabled checkout credential persistence, and strict Caps validation.
- Verify the installed native FFI modules against the exact runtime toolchain in Linux CI.
- Smoke-test the JSON, HTML, and POST JSON routes against the live Linux HTTP server with bounded connection and response timeouts.

- 将模板基线从 Calcit 0.13.32 提升到精确发布的 0.13.77。
- 将 HTTP 与已冻结 JSON 兼容模块更新到当前 C-safe 版本 0.3.14 和 0.0.17，避免工具链验证继续加载旧 Rust-value dylib。
- 使用包含已合并 Calcit 0.13.77 兼容修复的 Stir Template 0.0.12；Stir 已直接使用带类型解码，因此移除废弃的 Lilac 依赖。
- 使用精确的 0.13.77 CLI 规范化 Snapshot，将 server entry 绑定到现有的 `app.main` namespace，并向带类型的 JSON 序列化接口传入具体布尔值。
- 适配 Stir Template 0.0.12 的 `Option<String>` 标题资源边界，同时保持生成的 `<title>` 输出不变。
- 通过只读权限、明确可读的 Action 发布标签、禁用 checkout 凭据持久化及严格 Caps 验证加固 CI。
- 在 Linux CI 中验证已安装 native FFI 模块与精确 runtime toolchain 一致。
- 在真实 Linux HTTP server 上以有限的连接与响应超时烟测 JSON、HTML 与 POST JSON 路由。
