# Upgrade Calcit 0.13.77 / 升级 Calcit 0.13.77

- Raise the template baseline from Calcit 0.13.32 to the exact 0.13.77 release.
- Move the HTTP and frozen JSON compatibility modules to their current C-safe releases, 0.3.14 and 0.0.17, so toolchain verification no longer loads legacy Rust-value dylibs.
- Align the root Lilac request with Stir Template's resolved 0.5.5 requirement so strict Caps resolution is warning-free.
- Canonicalize the Snapshot with the exact 0.13.77 CLI; this only normalizes local namespace and definition map keys from legacy strings to symbols.
- Harden CI with read-only permissions, immutable action revisions, disabled checkout credential persistence, and strict Caps validation.

- 将模板基线从 Calcit 0.13.32 提升到精确发布的 0.13.77。
- 将 HTTP 与已冻结 JSON 兼容模块更新到当前 C-safe 版本 0.3.14 和 0.0.17，避免工具链验证继续加载旧 Rust-value dylib。
- 将根 Lilac 声明对齐到 Stir Template 实际解析的 0.5.5 要求，使严格 Caps 解析不再产生警告。
- 使用精确的 0.13.77 CLI 规范化 Snapshot；差异仅把本地 namespace 与 definition 的旧字符串 map key 规范为 symbol。
- 通过只读权限、不可变 Action revision、禁用 checkout 凭据持久化及严格 Caps 验证加固 CI。
